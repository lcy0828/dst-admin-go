# 定时任务与房间备份

[English](automation.en.md)

在“定时任务”中选择房间，然后添加任务。游戏命令可选择命令模板（包括自建模板），或直接填写多行 Lua 脚本；命令在指定世界执行。管理员保存的计划支持全部命令风险等级，每次执行保留任务结果与控制台记录。

“备份管理”选择房间后，可添加多个独立定时备份计划，修改时间、时区或暂停。支持五位 Cron（分、时、日、月、周），也支持第一位为秒的六位表达式。例如 `0 4 * * *` 表示每天 04:00，`0 */6 * * *` 表示每六小时。执行历史在“任务与记录”查看。

定时备份包含房间的全部世界。本机使用一致性快照；远程或跨机器房间在全部世界运行时使用热备份。部分世界运行时会短暂停止并恢复原运行世界，已经停止的世界不会被启动。热备份失败会记录错误，不会自动改为停服备份。创建计划不会自动清理历史备份，清理需单独配置。

计划由管理服务调度，关闭浏览器不影响执行；管理服务停止期间不会执行任务。
