# 日常开服指南

本指南从已经能打开管理页面开始。首次部署请先看[安装与启动指南](startup-guide.md)。页面右上角的“帮助与报错记录”可以搜索功能、查看常见操作及复制报错信息。

## 第一次开服

1. 跟随初始化向导创建管理员账户。普通单机开服沿用检测到的管理方式与数据位置即可；需要时再展开其他机器、存放位置等设置。
2. 安装游戏，或选择已有游戏安装。等待安装任务结束。
3. 创建房间，填写游戏中显示的名称、玩法、人数和可选密码，选择是否同时创建洞穴。存档名称会自动生成，也可以在创建前展开修改。
4. 登录 [Klei 服务器管理](https://accounts.klei.com/account/game/servers?game=DontStarveTogether)，创建饥荒联机版服务器，将 Token 粘贴到“开服凭证”。
5. 核对新房间的自动备份选项，再创建房间。已有房间的备份设置保持原样。
6. 回到首页启动房间。分别等待所选的地面、洞穴加载完成，再让朋友在游戏里搜索房间名称。

只启动地面也是有效选择。地面成功、洞穴失败时，仍应检查洞穴原因；游戏加载成功不等于已经验证外网可以连接。完成首次开服后，日常停服不会要求重新初始化。

导入存档时，先确认分析出的世界和房间名称，再执行导入。完成后检查开服凭证、模组及世界状态；导入本身不会自动启动世界。

## 朋友找不到或进不来

1. 确认需要的世界显示“运行中”，而非“正在启动”。
2. 确认游戏版本一致、房间密码正确，房间没有误设为仅局域网。
3. 在房间设置检查开服凭证。凭证格式正确不代表 Klei 已认证成功，以启动结果为准。
4. 云服务器需要在安全组和系统防火墙放行游戏端口。端口以各世界实际配置为准，参见[部署说明](startup-guide.md)。
5. 某个世界启动失败时，从房间查看日志或“分析日志与模组”。复制报错信息时先检查其中是否包含个人信息。

## 添加一个模组

1. 打开“模组”，确认当前房间。
2. 搜索创意工坊模组，下载后为需要的世界启用。
3. 打开模组设置，修改选项并保存。
4. 若页面提示需要重启，安排玩家退出后重启对应世界。文件保存成功不代表正在运行的游戏已应用新配置。

模组检查会展示发现的问题；没有发现异常也不能保证所有模组都支持新游戏版本。更多操作见[模组管理](mod-management.md)。

## 自动备份与恢复

1. 打开“备份”，选择房间，添加定时计划。
2. 选择“每天”并填写时间，或选择“每隔几小时”；核对时区和保留数量。
3. 保存后查看下次备份时间。任务或任务组被暂停时，计划不会执行。
4. 选择备份方式：“自动选择”在所有世界运行时不停服备份，其他情况会先停止运行中的世界；“不停服备份”无法完成时会报失败，不会擅自停服；“停服后备份”完成后仅恢复原先运行的世界。
5. 查看最近一次成功备份；计划已开启不代表最近一次已成功。
6. 需要停服时，沿用“游戏通知 → 操作前通知”的开关和提前时间，默认提前 30 秒公告；确认无人在线或关闭提醒时跳过。在线人数无法确认时仍会提醒。公告投递结果可在游戏通知历史中查看；投递失败会保留记录，取消倒计时会中止备份，不会停服。
7. 恢复前核对备份日期及世界。**备份之后的当前游戏进度会被覆盖**，确认后再恢复。

旧计划未设置备份方式时继续自动选择；仅改名称、时间或保留份数不会改变其备份方式。旧的复杂时间规则继续显示为“自定义计划”。仅修改名称不会改写原时间表达式。旧 ZIP 与完整房间备份仍按原来源处理，缺少校验信息的备份不会显示为已验证。

## 更新游戏和面板

游戏更新：点击顶部游戏版本提示，检查后核对需要更新的房间，再确认开始。更新会暂时停服、备份并启动原先运行的世界；原本停止的世界保持停止。进度可在右下角任务区查看，离开页面不会取消任务。已是最新版时直接关闭检查结果即可。

面板更新：在“系统设置 → 软件更新”查看版本及更新任务。只有支持取消的阶段可以停止下载；切换安装阶段以页面提示为准。详情见[游戏更新](game-updates.md)。

如果提示“结果尚未确认”，先查看原任务或刷新状态，不要反复提交相同操作。请求超时不代表游戏没有执行。

## 查玩家背包与活动

从“玩家”搜索昵称，选择玩家后查看背包或活动。背包会标明实时读取或存档快照及时间；存档内容可能落后于当前状态。部分读取失败不代表对应物品不存在。

活动的时间线、轨迹和战斗仅覆盖已采集的范围。页面提示记录缺失时，不把缺少记录解释为玩家没有活动；详细采集情况可以展开查看。

## 升级兼容

本轮界面调整沿用原有房间、世界、任务与权限接口。原路由和链接仍然可用；已有目录、备份计划、自定义插件模板和 MCP 连接设置不会因为页面调整而重新生成。

升级前按[升级与数据保护](startup-guide.md#升级与数据保护)保存配置和数据。面板、Agent 与机器人插件可分别升级，功能以各组件实际支持的能力为准；旧组件没有提供的状态会显示待确认。没有历史安装验证的版本，不承诺任意跨度直接在线升级。
