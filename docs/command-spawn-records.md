# 生成操作的位置记录

在首页控制台或游戏工作台执行内置生成命令后，命令结果会显示“生成记录”。页面、OpenAPI 和 MCP 使用同一条持久化回执；刷新页面后可通过命令历史读取。

支持 `spawn_entity`、`spawn_domesticated_beefalo`、`give_item`、`give_blueprint` 和 `give_recipe_materials`。记录范围为主要生成对象；驯牛命令附带的鞍具和牛铃不单独列入。原始 Lua 和自定义命令保留原有执行能力，但不会自动改写脚本或追踪 `SpawnPrefab`。

每条记录包含 Prefab、数量、可取得的运行时实体标识，以及去向：

- `world`：实体放置后读取到的实际 XYZ 坐标。
- `inventory`：物品已确认位于物品栏中，没有独立的地面落点。
- `unresolved`：暂时无法确认。例如原物品已被堆叠合并、移除或被模组处理；不会根据玩家位置补造坐标。

玩家执行时的位置保存在 `spawnAudit.origin`，与实体实际落点分开。坐标是记录当时的观察值，不是持续跟踪；实体可能随后移动。`entityGuid` 仅用于识别当前运行中的实例，重启、重新载入或回档后不能作为稳定身份使用。

`spawnAudit.status` 为 `complete`、`partial` 或 `unavailable`。每次最多保留 40 个主要对象的明细，额外数量通过 `omitted` 表示；命令异常中断、输出截断或旧版本缺少位置采集时，不能把缺少记录解释成没有生成。`total` 仅统计到达记录步骤的对象，命令未完成记录序列时省略；不保证覆盖任意模组的其他副作用。

记录直接随本次同步输出保存，不增加后台采样、世界实体扫描或每个实体的网络请求。记录失败不会导致原本的生成操作失败，也不会重放命令。同步回执成功仅说明本次执行返回，不证明实体随后的初始化或游戏进程持续健康。
