新增受控只读游戏查询，改善外部 MCP 客户端兼容性，并修复离线背包读取和服务日志级别误判。

- **受控只读查询：** 新增 `api_queryRoomWorld` 和 `api_getRoomWorldQueryRun`，支持世界信息、指定分片在线玩家及按 Prefab 统计实体数量。服务端固定查询白名单，不接收 Lua、自定义命令或调用者声明的只读标记；本机与 Agent 共用结果契约。提供限流、并发、扫描、执行时间和输出预算，不增加闲时扫描。
- **可信查询结果：** 区分成功、部分结果、失败、超时、不可用与结果不确定；`sent` 不当作执行成功，空输出不解释成数量为零。不确定查询可补读原回执，不自动重发，也不会自动安装或修复 Runtime。接入说明见 [受控只读查询](https://github.com/lcy0828/dst-admin-go/blob/v1.3.13/docs/controlled-world-queries.md)。原通用控制台和 Lua 执行入口继续供管理员使用。
- **MCP 兼容与并发：** 新增连接参数 `pagination=off`，兼容只读取第一页工具目录的客户端，默认仍按每页 64 项分页。该参数不改变工具权限。分离页面 AI 长对话与 MCP 入口额度，避免对话占用全部入口；实际工具执行仍保持有界并发。
- **离线背包：** 修复正常原生玩家快照因末尾包含小地图等二进制附加数据而返回 `SAVE_INVALID`。按声明长度读取背包正文，不执行存档代码；截断、异常边界和超限仍明确报错。在线实时读取方式保持一致。
- **服务日志：** 根据明确的级别标签识别严重程度，避免正常发送的控制台命令因正文包含 `ERROR`、`WARN` 或错误提示模板而被误记成报错；为相关真实失败和警告补充显式标签。

**升级：** 可在 **系统设置 → 软件更新** 在线升级控制端及内嵌页面；远程节点的离线背包修复需要同步升级 Agent。面板在线更新不会主动停止或重启游戏世界，请等待正在执行的后台任务完成。Docker 用户可使用 `v1.3.13` 或 `latest`。外部 MCP 客户端请刷新工具清单；目录筛选和只读注解不会缩小接入密钥本身的权限，向普通用户开放查询时仅开放专用查询工具。

Local and Agent execution share bounded concurrency, scan, time and output budgets without idle scanning.
- **Result evidence:** distinguish complete, partial, failed, timed-out, unavailable and uncertain outcomes. Delivery alone is not success and missing output is not zero. Read the original late receipt without replaying a query or automatically repairing Runtime. Administrator console and Lua tools remain available.
- **MCP:** support `pagination=off` for clients that only read the first tool page; default pagination remains 64 items. The option does not change permissions. Separate MCP admission from long-running page conversations while retaining bounded tool execution.
- **Offline inventory:** accept native player snapshots containing binary classified/minimap data after the declared Lua payload. Parse only the declared data without executing Lua; preserve malformed-input and resource-limit checks.
- **Service logs:** use explicit severity labels so successful command-delivery messages containing error templates are not misclassified. Add labels to relevant actual failures and warnings.

Panel updates do not deliberately restart game worlds; wait for active tasks to finish. Docker tags are `v1.3.13` and `latest`.
