# v1.3.14

修复游戏更新失败后被维护状态卡住的问题，并改善玩家状态与背包显示。

- **更新校验与恢复（#27）：** 本机和 Agent 统一使用固定的 SteamCMD 校验命令，记录校验与尝试次数。明确的文件损坏终态最多额外校验一次；超时或不确定结果不自动重发。读取 Steam 安装状态，避免仅凭 Build 相同误判安装完整。
- **LuaJIT 恢复：** 校验前暂时还原官方可执行入口，完成后恢复已识别的 LuaJIT 启动入口；兼容先前被 Steam 更新覆盖的完整安装。可选加速组件修复与官方安装验证分别记录；恢复时明确确认加速模式不可用且世界已停止，才改用原版运行时启动，并在页面及 API/MCP 标注警告，保留原偏好。
- **维护出口：** 安装全部验证通过后，可以选择“结束维护，保持当前状态”，再修复加速组件或手动启动。此操作不会启动、停止或回退游戏；部分安装、未知写入或不明进程状态仍受保护。详见[游戏更新与恢复](https://github.com/lcy0828/dst-admin-go/blob/v1.3.14/docs/game-updates.md)。
- **玩家状态：** 查看当前玩家列表时，有界合并已有 Runtime 快照，减少重新上线后仍显示旧离线记录的情况。节点读取失败时保留旧记录并提示状态尚未确认。
- **背包显示：** 使用资源目录补齐标准物品中文名称，支持中文搜索及容器内搜索；保留模组自定义名称。存档来源不明确时清除旧结果，其他刷新失败会标明上次读取结果。

**升级：** 控制端与页面可在线升级；远程更新修复需要同步升级 Agent。升级面板不会主动重启游戏世界，请先等待正在进行的更新等后台任务结束。Docker 标签为 `v1.3.14` 和 `latest`。AstrBot 配套开发未包含在本版本。

Fix game-update recovery deadlocks and improve player presence and inventory display.

- Share bounded validated SteamCMD writes across local Runtime and Agents; retry explicit corrupt-file terminal failures once and verify manifest installation state. Never automatically resend uncertain writes.
- Recover recognized overwritten LuaJIT launchers, separate optional accelerator warnings from official game integrity, and restore with the official runtime only after a definite accelerator rejection and confirmation that no world process exists. Preserve original preferences and expose fallback warnings.
- Allow ending verified maintenance without further world restarts. Incomplete installations, unknown writes and uncertain processes continue to block unlocking; protection backups and release evidence remain available.
- Merge existing fresh player snapshots with bounded reads, label uncertain cached presence, restore standard inventory localization and Chinese search, and avoid showing an old inventory as a newly selected ambiguous source.

Update Agents for remote update recovery. Panel updates do not deliberately restart game worlds; wait for active maintenance jobs to finish. AstrBot companion development is excluded from this release.
