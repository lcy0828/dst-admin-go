# v1.3.20

修复 v1.3.19 中仍可能出现的模组搜索和资料加载失败，继续完善 [Issue #29](https://github.com/lcy0828/dst-admin-go/issues/29) 相关修复。

- **恢复工坊资料读取：** 修正部分 Steam 访问线路返回限流错误的问题，覆盖名称搜索、按 ID 查询和公开 Beta 模组详情，继续使用已配置的代理。
- **限流提示更准确：** 真正遇到 Steam 限流时显示等待秒数，等待期间阻止同一查询反复提交；不会自动重试，也不会清空已有结果。按 ID 查询失败时不再误报为名称搜索不可用。
- **减少无效请求：** 排队中的工坊请求会遵守刚收到的限流等待时间，避免继续请求上游。保留并发、超时、响应大小和缓存限制。

本次只调整工坊资料读取与页面提示，普通面板升级保留配置、存档和运行中的世界。

## English

- Fix Workshop metadata requests that could still receive rate-limit responses on affected Steam routes, covering name search, ID lookup and eligible public Beta item details through the configured proxy.
- Show the upstream retry countdown, prevent repeated submissions of the same query, retain earlier results and distinguish ID lookup errors from unavailable name search. No automatic retry is introduced.
- Make queued Community requests honor newly received rate limits while retaining existing concurrency, timeout, size and cache bounds.

Ordinary panel updates preserve configuration, saves and running worlds.
