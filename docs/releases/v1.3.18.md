# v1.3.18

修复部分公开 Beta 模组无法按 ID 搜索或下载的问题，改进游戏更新、备份和玩家操作，并将 AstrBot 查询与播报合并为一个插件。模组修复对应 [Issue #29](https://github.com/lcy0828/dst-admin-go/issues/29)，感谢提交反馈。

## 模组与游戏更新

- **公开 Beta 模组：** 当 Steam 详情接口无法提供部分公开条目的资料时，按 ID 或链接查询、显式下载及依赖解析会核对公开工坊页面。本机和 Agent 共用检查规则；私有条目、其他游戏和身份无法确认的页面继续拒绝，不会将未知版本显示为最新版。
- **统一更新入口：** 顶部可以检查游戏更新，并打开同一更新窗口。页面展示已有检查结果，更新影响与可选说明分开展示，任务进度集中在右下角，支持离开页面后继续查看。
- **面板下载可取消：** 安装切换前，可以取消正在下载或已经准备好的更新包，再调整代理或下载设置。取消不会中断已经开始的版本切换。
- **常用玩家操作：** 无敌模式、制造模式回到默认操作区；移速、清除异常等放入更多选项。

## AstrBot 饥荒助手 v0.3.0

- **合并查询与播报：** 一个插件提供常用查询、自然语言助手和游戏事件播报，简化连接与群设置。房间从面板授权中同步，支持群内启用、订阅和开关聊天播报；管理仍需单独授权。
- **常用请求直接处理：** 菜单、房间状态、玩家与背包等查询优先直连面板。补充玩家昵称识别、消息引用和后续选择，避免菜单已回复后模型再次回答。
- **接入固定工作台能力：** 已授权的玩家操作、发放物品和受限实体生成使用服务端固定指令，并核验执行回执。未确认结果不会被当作成功，也不会自动重放写入。
- **改善消息阅读：** 房间、背包和聊天使用清晰的分组展示，补充标准物品中文名称；清理 QQ 中不适合展示的 Markdown 标记。消息模板可按需编辑，保留字段校验。
- **恢复播报：** 改进断线恢复、首次状态建立和聊天同步，减少重复播报及旧游标造成的漏读。

## 备份与日常使用

- **定时备份可选方式：** 与手动备份保持一致，可以选择不停服或停服备份。已有计划保留原先方式；停服备份支持提前发送游戏公告，取消和异常恢复不会误触发后续停服。
- **聊天记录恢复：** 改善日志轮转、文件替换及旧版本游标迁移时的同步，无法确认的历史范围会保留缺口提示。
- **页面更易理解：** 调整创建房间的更多设置，简化多处说明和错误提示，新增使用帮助；MCP 接入按权限档位说明包含关系，兼容已有授权设置。
- **性能与资源包：** 修正性能报表中重复分片记录的汇总，工作台明确展示资源包未安装、安装中和已安装状态。

控制端与独立 Agent 建议一同升级。普通面板更新保留存档、配置及运行中的游戏世界；游戏服务端更新和停服备份仍按各自确认的流程执行。

AstrBot 需要单独安装本版本附件中的 `astrbot_plugin_dst_companion.zip`。已有配置保留；使用独立旧播报插件时，先迁移并确认群订阅，再停用旧插件，避免重复播报。
