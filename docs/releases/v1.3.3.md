改善本地模组管理，修复首次开服和无人暂停时的 Runtime 就绪、采集与命令执行。

- **本地模组（#11）：** 支持管理运行节点上已安装的非创意工坊模组，查看详情、配置并接入世界；重建模组配置、导入与恢复时保留本地模组，不再因缺少 `workshop-` 前缀而遗漏。
- **AI / MCP 接口（#12）：** 补齐缺失的管理接口说明，明确参数与适用范围；发现工具时优先提供规范接口，保留旧接口兼容并标注替代项。
- **首次启动（#13）：** Runtime 在世界初始化完成时执行首轮采集；首次生成世界时的保存日志不再被提前判为启动完成。页面显示启动阶段，并区分已安装与当前运行的 Runtime 版本。
- **无人暂停（#14）：** 修复空服暂停后采集状态陈旧导致 Lua 命令被拒的问题。完全休眠时保留当前进程的有效采样，显式操作前按需确认；普通暂停与完全休眠均不会因只读采集而推进游戏时间。命令、实体目录和诊断保持有期限执行，不自动重放业务命令。
- **备份保护：** 保存保护增加独立的控制端期限，复制后再次核验保护状态，释放需收到持久回执，避免保护失效后发布一致性备份。
- **导入与恢复：** 保留采集器状态并校验当前进程、Session 和分片身份，避免复用旧进程的数据；远程 Agent 的制品缺失与实际读取失败分别处理。
- **LuaJIT2：** 内置更新为上游 [@fesily 的 DontStarveLuaJIT2](https://github.com/fesily/DontStarveLuaJIT2) 3.3.2 预发布提交 的 Debian 兼容构建；继续支持运行节点自行安装和更新。

**升级：** 在 **系统设置 → 软件更新** 更新控制端；独立 Agent 在 **机器管理** 中更新，以获得相同的 Runtime 行为。Docker 用户也可拉取 `v1.3.3` 或 `latest` 后重建容器。前端随程序和镜像提供；无需删除或重新创建游戏存档。
