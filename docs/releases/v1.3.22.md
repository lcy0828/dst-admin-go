# v1.3.22

修复游戏管理员无法通过 MCP 使用无敌／上帝模式和制作／创造模式的问题，并补齐同类玩家操作。

- **游戏管理权限一致：** 原生 API、MCP 工具发现和实际调用统一允许授权房间内的无敌、制作、复活、踢人、封禁／解封、提醒、死亡和重选角色操作；补齐玩家详情、玩家刷新与备份列表的管理权限。
- **AI 能找到并使用：** 任务目录新增无敌、制作等固定玩家能力，支持常用中文别名。开关必须明确提供 `true/false`，任务准备、执行和结果回读继续分开，重复提交不重复执行。
- **保持权限边界：** 游戏查询密钥仍不能修改游戏，跨房间访问仍拒绝；通用 Lua、管理员名单、集群令牌和面板维护不开放给游戏管理。旧复活工作台及 MCP 分页配置保持兼容。
- **AstrBot v0.4.1：** 补齐玩家工具参数与中文群权限设置名称。保留已有群授权；维护者明确授权后才开放新操作。旧插件 v0.4.0 仍可通过能力目录和通用任务入口使用已授权的新能力。

普通面板升级保留配置、存档和运行中的世界。插件安装包单独提供；本次未配置发布签名，插件请手动更新。完整真实 QQ 群交互仍需部署验收。

验证：324 项 AstrBot 自动化测试通过；AI 接入、HTTP 权限、玩家管理与 API 契约的后端回归和并发检测通过，OpenAPI 契约检查通过。测试使用合成数据与执行替身，未修改实际玩家或世界。
