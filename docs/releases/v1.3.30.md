# v1.3.30

修复自动备份后世界卡在暂停状态、弹窗内确认按钮被遮挡等问题，统一玩家模式，并提供可随面板扩展能力的 AstrBot 饥荒助手 v0.4.7。

- **备份恢复：** 释放失败会有限重试并核对游戏回执；恢复失败、写盘未结束或结果不确定时不会报告成功。取消不会清空仍在执行的保存计数，旧任务不能解除新任务的保护。保留世界原先的暂停状态，进程仍在但没有响应时提供明确提示和重启入口。解决 #35。
- **弹窗操作：** 模组等页面内打开的确认框始终位于原对话框上方；输入框及运行方式选择同步修正。解决 #34。
- **玩家模式：** 玩家操作、工作台、旧 API 和内置命令使用同一套状态管理。普通免伤、上帝模式、制造、锁血、必杀、隐身、踏水和穿墙可以分别开启和解除，关闭一种会保留其他模式仍需要的效果；一击必杀尊重玩家伤害与格挡保护。无法安全恢复的旧模式会提示玩家重新进入游戏。
- **能力发现：** 从 OpenAPI 契约生成查询、权限、参数、确认及任务关系。插件通过 `dst_find`、`dst_read`、`dst_run`、`dst_result` 按需使用兼容的新接口，无需逐项增加插件分支。原 API、MCP 工具名和分页兼容设置继续保留。
- **群内操作：** 常见请求直接处理，其他自然语言自动进入模型；统一昵称、引用通知、最近目标和参数补齐。复活无需重复确认；危险修改仍按服务端要求确认。游戏更新预检作为读取处理，实际更新另行确认，并显示对应任务结果。
- **权限与通知：** 支持按真实群身份缩小插件权限。普通事件通知默认开启，保留已有明确关闭的设置；聊天与模组自定义消息分别设置。死亡复活记录更快落盘，避免为通知新增持续扫描。
- **房间与网络：** 新增带房间名确认的整房间重置任务，默认先备份，可明确跳过；请求了备份但备份失败时取消重置。模组搜索为慢代理响应保留合理等待时间。
- **工作台扩展：** #30 的能力对照与边界已整理至[支持范围](../workbench-support.md)，包含玩家模式、天气星象、附近实体、角色能力、保存地点和地图工具。第三方模组的付费授权、客户端专属交互不作为服务端已支持能力。

## 升级与兼容

更新包内含配套页面。AstrBot 请安装本 Release 的 `astrbot_plugin_dst_companion.zip`（v0.4.7），保留原配置与状态；旧插件可以继续使用原入口，但新的自动发现与交互需要先升级插件。后续新增符合现有协议的面板接口可通过发现使用，不自动扩大旧群权限。

相关游戏功能需要 Runtime 2.4.26；远程机器同时更新 Agent，再通过运行脚本更新入口应用。面板程序更新不会主动重启游戏世界；无法识别恢复依据的旧玩家模式可能需要该玩家重新进服。

## 验证

109 个 Go 测试包通过 race 检查；1006 项前端测试、509 项插件测试和 15 项发布脚本测试通过。另有真实 Go HTTP / AstrBot 集成检查，验证插件无需新分支即可发现并调用新增接口。OpenAPI、能力目录、前端 lint 与构建、Go vet/build 和漏洞调用检查通过。

游戏行为测试执行发布中的 Lua，使用合成游戏组件验证保存、暂停、回执和本机／Agent 读取。未在在线游戏世界或真实 QQ 群执行本次验收；弹窗层级通过自动测试检查，未把它等同于浏览器点击验收。
