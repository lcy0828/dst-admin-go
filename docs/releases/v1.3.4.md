改善命令回执确认，更新原版实体目录，并为外部 AI 接入提供可分类、按需发现的 MCP 工具。

- **命令回执（#15）：** 本机与 Agent 的默认回执确认窗口从 5 秒延长至 15 秒。严格遵守请求期限；发送后超时、取消或无法确认结果时显示“结果未确认”，保留可能已执行的状态，不自动重放命令。排队可取消，控制台请求的 `Server-Timing` 可查看各阶段耗时。
- **Runtime：** 内置版本更新至 **2.4.14**。命令回执关联命令模块自身的实例标识，避免与独立的遥测实例混淆；兼容旧版健康文档。
- **实体目录（#16）：** 从 DST **759671** 重建 **8,025** 个已注册原版实体的显示目录，补齐新版物品与官方中文名称。新增翻译状态、名称来源、构建时间及来源校验值；保留旧客户端的名称回退行为。提供可复现的目录重建脚本，查询仍使用一次加载的内存数据。
- **MCP 工具（#17）：** 工具提供多标签、读写类型、风险与运行条件，以及标准 MCP `annotations`。默认连接仅列出 9 个常用与发现工具，通过 `find_api` 获取参数 Schema，再用 `call_api` 调用完整管理能力；旧工具名称仍可调用。列表支持分类筛选与每页最多 64 项的标准游标分页。
- **前端：** 合并原版与世界实体时保留中文名称及其翻译来源；同步管理接口分类契约。

**MCP 客户端：** 保留 `/mcp` 使用精简列表；按领域发现可使用 `/mcp?tags=backup&access=read`；需要全部规范工具时使用 `/mcp?view=all`，依赖旧全量列表的客户端使用 `/mcp?view=legacy`。详见 [AI 接入说明](https://github.com/lcy0828/dst-admin-go/blob/master/docs/ai-assistant.md)。

**验证与范围：** 全量 race 测试、接口契约校验和前端回归通过。Linux 双世界实测的 10 条命令全部仅执行一次，回执约 168～183 毫秒；另有超过原 5 秒边界的延迟回执回归。尚未在 WSL2 实机复现 Issue #15 报告的固定约 5 秒落盘延迟，本次修复针对超时边界与执行结果判定。

**升级：** 在 **系统设置 → 软件更新** 更新控制端；独立 Agent 在 **机器管理** 中更新。已启用的受管 Runtime 随对应节点升级自动维护，可在 Runtime 状态页核对运行版本。Docker 用户也可拉取 `v1.3.4` 或 `latest` 后重建容器，前端随程序和镜像提供。

Improves command receipt confirmation, refreshes the vanilla entity directory, and adds classified, on-demand MCP tool discovery for external AI clients.

- Extend the default local and Agent receipt window from 5 to 15 seconds. Respect strict deadlines, allow queued cancellation, and preserve an uncertain outcome after dispatch without automatically replaying commands. Console responses expose request stage timings (#15).
- Bundle Runtime **2.4.14**, correlating receipts with the command module's own producer identity while retaining compatibility with older health documents.
- Rebuild display metadata for **8,025** registered vanilla Prefabs from DST **759671**, including official Chinese names, translation provenance and reproducible build metadata. Existing fallback fields remain compatible; queries use the directory loaded once in memory (#16).
- Add multi-domain tool tags, access/risk/runtime metadata and standard MCP annotations. Default discovery lists nine common and discovery tools; `find_api` returns argument schemas and `call_api` executes the discovered operations through existing validation and execution guards. Existing tool names remain callable. Filtered listings use standard cursor pagination with at most 64 tools per page (#17).
- Preserve translation provenance when merging frontend resource directories and synchronize the management operation manifest.

**MCP clients:** use `/mcp` for compact discovery, `/mcp?tags=backup&access=read` for a filtered view, `/mcp?view=all` for canonical tools, or `/mcp?view=legacy` for the full compatibility listing. See the [integration guide](https://github.com/lcy0828/dst-admin-go/blob/master/docs/ai-assistant.en.md).

**Validation:** full race tests, contract checks and frontend regression passed. Ten commands on a real Linux Master+Caves setup each executed once, with receipts in approximately 168–183 ms. Delayed receipts beyond the former five-second boundary are covered by regression tests. The fixed approximately five-second WSL2 persistence delay reported in #15 has not been reproduced on a real WSL2 host; this release addresses the timeout boundary and outcome handling.

**Upgrade:** update the Controller under **System settings → Software updates**, and standalone Agents under **Machines**. Enabled managed Runtime installations are maintained when their node upgrades; check the running version on the Runtime status page. Docker users can pull `v1.3.4` or `latest` and recreate their containers. The frontend is embedded.

Thanks to [@hxyinan](https://github.com/hxyinan) for the detailed reports and suggestions in #15, #16 and #17.
