# v1.3.28

游戏服务端更新现在显示 SteamCMD 实际下载与校验进度。游戏工作台补齐资源快捷操作、八种玩家模式、角色用品、地皮编辑、阵列与更多世界管理能力，配套 AstrBot 插件升级到 v0.4.5。

- **更新进度：** 更新详情和右下角任务框显示当前阶段、已处理大小、总大小、可用时的下载速度和耗时。本机与 Agent 使用相同进度格式；没有可靠总量、输出过期或连接中断时明确等待，不编造百分比，也不把下载完成当成世界恢复成功。
- **物品操作更方便：** 支持拼音及首字母搜索、收藏、制作分类、右键与触屏菜单、中键快捷入口、批量生成及已拥有皮肤的选择记忆。
- **玩家与角色：** 八种模式可分别开启、关闭并一键解除；模式记忆默认关闭，需要明确启用。补齐状态恢复、基础工具、18个原版角色用品及实际组件支持的角色专项。
- **世界与地皮：** 补齐地图选点生成、地皮发放与铺设、整齐阵列、全世界同类统计与清理、轮流定位、农田养分和巨大农作物、特殊设施、昼夜分段与指定天数等操作。完整清单见[工作台支持范围](../workbench-support.md)。
- **MCP 与机器人：** 新能力复用动态目录和既有任务工具，无需一次加载一批新工具。插件可直接识别明确的模式开关，修改仍检查权限并由原用户确认。
- **结果更可靠：** 修改前冻结目标和参数，确认只消费一次；大范围读取和多对象操作有界分帧，不自动重做已尝试的修改。数量结果缺失不解释为0，迁移源端消失不解释为已经到达，模式关闭保留第三方接管的设置。

## 升级与兼容

更新包内含配套页面。新扩展需要 Runtime 2.4.24；请通过现有运行脚本更新入口更新相应机器，远程机器还应更新 Agent。旧 Runtime 明确提示更新，原有 API、固定查询和旧回执继续兼容，不回退到任意脚本。

AstrBot v0.4.5 通过本版本 Release 中的 `astrbot_plugin_dst_companion.zip` 单独安装或升级；面板更新不自动扩大群权限。客户端错误技能提示另有[可选客户端助手](../../integrations/dst-admin-client/README.md)，服务端同步不能代替客户端界面修复。

发布和更新面板程序本身不会主动重启游戏世界。移除道路会保存并重载，重置世界等操作仍按页面说明由用户单独确认。

## 验证

全仓105个 Go 测试包、前端1003项和插件354项测试通过；相关 race、vet、构建及 OpenAPI 契约检查通过。隔离原生世界验证了地皮、生成、统计、模式切换、特殊设施和洞穴前提等行为；界面检查覆盖桌面与手机宽度。

尚未完成真实登录客户端的地图显示、技能弹窗，以及真实玩家跨世界迁移到达的验收；这些功能不得据“命令已提交”报告效果成功。下载进度已通过本机、Agent 与模拟 SteamCMD 输出回归，未进行真实 Steam 下载带宽测试。
