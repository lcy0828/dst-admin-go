# v1.3.24

修复大型模组信息读取失败导致整批更新检查受阻的问题，完善模组更新中断后的恢复，并让定时任务页面明确显示当前房间和读取状态。

- **大型模组正常检查：** 改进受限模组信息解析，解决 Insight 等大型模组信息无法读取的问题。个别模组暂时无法确认版本时，保留其他模组的检查结果；未知版本不会被当作已是最新。
- **模组更新更可靠：** 更新前再次核对确认的模组和受影响房间。按机器记录下载结果、按世界记录重启结果；重试时核验并继续未完成步骤，已完成的世界不重复重启。超时或回执缺失会显示尚未确认，不自动重复操作。
- **定时任务先选房间：** 单个房间自动选中，多个房间恢复仍可访问的上次选择，否则提示选择房间。任务、分组、记录、统计及导入导出统一使用当前房间，不再将未选择房间显示成“暂无任务”。
- **切换房间更清楚：** 读取失败、暂无任务和筛选无结果分别显示；切换房间后旧数据与未提交的操作确认失效，避免把原房间的编辑提交到新房间。统计读取完成后才展示。
- **API / MCP 保持兼容：** 沿用现有模组检查和更新工具，增加逐项检查与恢复进度，旧客户端仍可使用原请求。AstrBot 插件仍为 v0.4.2，无需因本次修复升级插件。

All-in-One 升级面板即可获得本机修复。远程机器需同时升级 Agent，才能使用新的模组信息解析器。面板升级保留存档和运行中的世界；主动执行模组更新仍会按所选操作恢复相关世界。

本版通过后端自动化回归、相关并发检测和前端 975 项测试、检查与构建。不同模组组合与旧 Agent 的实机表现仍需在对应环境确认。

修复 [#32](https://github.com/lcy0828/dst-admin-go/issues/32) 和 [#33](https://github.com/lcy0828/dst-admin-go/issues/33)。工作台扩展 [#30](https://github.com/lcy0828/dst-admin-go/issues/30) 继续跟进。详见[模组管理](../mod-management.md)与[自动化任务](../automation.md)。

## English

- Fix bounded metadata evaluation for large mods such as Insight. Preserve usable update-check results when individual versions are unknown; unknown does not mean current.
- Validate the confirmed mod set and affected rooms before updating. Persist installation and world recovery progress, verify completed downloads before resuming, and avoid restarting worlds already confirmed ready. Missing or uncertain receipts never trigger automatic replay.
- Require a valid room selection throughout automation pages. Restore an accessible selection or automatically select the sole room, and distinguish selection, loading, error, empty and filtered-empty states.
- Invalidate stale page requests and unsubmitted confirmations when changing rooms, management scope or account. Display statistics only after successful loading.
- Keep existing API/MCP tools and legacy update requests compatible. Add optional check and recovery details. The bundled AstrBot plugin remains v0.4.2.

Upgrade remote Agents to receive the metadata parser fix. All-in-One receives it with the panel update. Panel updates preserve saves and running worlds; explicit mod updates still restore affected worlds as requested. Automated backend regressions, targeted race checks and 975 frontend tests passed; real mod combinations and older Agents remain environment-dependent.
