修复玩家活动记录采集中断、LuaJIT 自动化重启误判，以及首次启动时容量清单缺失的问题。

- **活动记录持续采集：** 修复活动分段切换和异步落盘异常后采集停滞的问题。分段与索引按同一批次提交，写入结果未确认时保持保护；控制端记录恢复进度，有限重试并继续导入后续可验证的数据。
- **采集状态与重新同步：** 活动记录页面区分配置是否生效、节点是否产出、同步积压与历史缺口，并提供“重新同步”入口。重新同步唤醒现有采集任务，不重启世界、不清空记录。真正丢失的数据会明确标记为缺失，不补造活动。
- **轨迹与 MCP：** 坐标轨迹支持紧凑查询，在分页前过滤坐标数据；跨世界、运行实例、会话和已知缺口不连线。活动查询返回覆盖情况，MCP 能力检索补充嵌套参数示例与说明；新增 `resyncRoomPlayerActivity` 操作，可通过 OpenAPI / MCP 重新同步后查询状态。
- **LuaJIT 启动与重启（#25 后续反馈）：** 修复旧房间未保存安装 ID 时，将空值与实际安装 ID 不一致而误判 LuaJIT 不可用的问题。页面、自动化与 MCP 执行统一解析实际安装，支持显式选择和继承当前方式；无需手动填充启动偏好表。任务重试保留已解析的安装身份，位置变化时在停止世界前报错。
- **容量检查：** 启动前按需刷新所选节点缺失或过期的清单，支持仅通过 API / MCP 使用、尚未打开面板的场景。复用新鲜缓存与进行中的采集；多安装清单不完整时保持未知，节点离线或取消配置后不再误用旧缓存。
