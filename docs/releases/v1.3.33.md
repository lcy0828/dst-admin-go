# v1.3.33

新增世界与模组配置文件在线编辑，并简化单机面板的常用操作。

- **世界配置：** 在世界设置中查看和编辑 `server.ini`、`leveldataoverride.lua` 原文，支持语法检查、格式化和保存前对比。粘贴配置时兼容常见 Klei 文件头、编码标记与换行格式，并检查世界类型和分片角色。
- **模组配置：** 在线编辑整份 `modoverrides.lua`，预览模组增删和缺少的文件。可选择将配置同步到多个世界，并在保存前下载缺少的工坊模组；本地自制模组仍需自行安装。
- **保存与兼容：** 使用实际运行节点上的文件和配置版本，拒绝覆盖已经被其他操作修改的内容。本机和远程节点沿用现有保存机制；保存配置不会自动重启世界，也不会重新生成已有地图。
- **界面：** 简化单机部署的设置和首次使用引导，在需要时再展示多机管理选项；改善世界设置切换、玩家列表、刷新设置及空白页面的操作提示。
- **登录：** “记住我”会实际控制登录 Cookie 的保留方式。未勾选时使用浏览器会话 Cookie，服务端有效期仍然适用；旧客户端不传该选项时保持原有行为。
- **API 与 MCP：** 同步配置文件读取、预览和保存接口的参数、结果与权限说明。新增原文编辑能力属于面板管理权限，只读预览不会保存文件或执行 Lua。

## 升级说明

管理程序包含配套页面；已有房间、配置和 AstrBot 设置继续保留。配置保存成功只表示文件已写入，游戏何时采用新配置取决于对应设置；通常需要另行重启，地图生成规则只影响新生成的世界。

AstrBot 插件继续使用 v0.4.8，本次无需升级插件。Runtime 脚本及 Agent 通信能力要求保持兼容。面板升级不会主动重启游戏世界。

## English

- Edit world INI/Lua source files and complete Mod overrides online, with syntax validation, formatting, change previews and revision-checked saves.
- Support pasted Klei configuration files, selected-world Mod synchronization and optional missing Workshop downloads through the existing Runtime publication protocol.
- Simplify the single-host experience, progressively expose fleet controls, and improve world settings, onboarding, player lists and refresh controls.
- Honor the login remember preference while preserving existing clients' persistent-session behavior.
- Publish matching API/MCP contracts for the new panel-management operations. Previews do not write files or execute Lua; configuration saves do not restart worlds or regenerate existing maps.
- Preserve existing Runtime/Agent compatibility. AstrBot remains v0.4.8; no plugin upgrade is required.
