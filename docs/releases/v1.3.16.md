# v1.3.16

修复页面软件更新被旧任务阻挡的问题，新增可自定义的 GitHub 加速前缀，同时更新 AstrBot 伴随助手 v0.2.1。软件更新修复对应 [Issue #28](https://github.com/lcy0828/dst-admin-go/issues/28)。

- **旧任务自动对账：** 通过镜像或安装包升级后，已被健康运行版本覆盖的待安装、失败或中断任务会明确标记为已失效，新版更新入口保持可用；不会把旧任务误报为安装成功。
- **失效更新包恢复：** 已下载的安装包缺失或校验失败时，可以重新下载，无需清空更新目录。禁止重复安装相同版本，保留有效的未来版本更新包和完整校验。
- **自定义 GitHub 加速：** 软件更新设置新增可见的 HTTPS 加速前缀，默认 `https://ghfast.top/`，留空恢复默认。版本信息、校验文件、安装包与续传共用设置；网络代理仍独立配置。控制端、Agent 自行下载及控制端传包均使用对应下载机器的设置。
- **更新交互与 Agent 回执：** 新版入口不再被旧任务遮住；确认安装绑定具体任务，失效任务清理浏览器中的自动安装意图。Agent 遇到外部升级使任务失效时明确结束等待，不重复下发安装。
- **AstrBot 菜单与消息路由：** 当前用户可在菜单有效期内直接回复序号、翻页或取消，修复必须额外 @ 或引用才能选择的问题；过期菜单和越界序号明确提示，保留用户、群及权限隔离。使用框架的明确唤醒标记兼容引用回复，普通群聊不触发查询。未启用群的 `/dst` 请求返回配置提示，不自动启用该群。
- **AstrBot 查询体验：** 新安装默认混合模式，常用指令直查，其他自然语言继续使用原有模型；保留已有显式模式配置。补充中文房间编号、查房汇总、在线玩家与模组展示；背包按装备、物品栏和嵌套容器展示名称、数量与已采集耐久/次数。修正只读连接自检误报缺少写能力。

控制端与独立 Agent 均需升级才能使用全部修复。普通面板更新保留存档、配置和运行中的游戏世界。AstrBot 伴随助手需单独更新 ZIP；已有 shortcut 配置希望自然语言继续交给模型时，手动切换为 mixed。事件播报插件版本保持不变。

## English

- Reconcile obsolete online-update tasks after healthy external image/package upgrades without falsely reporting the old installation as successful.
- Re-download missing or invalid prepared packages, reject same-version reinstallation and retain valid future packages and integrity checks.
- Configure an HTTPS GitHub mirror prefix for release metadata, checksums, archives and resumable downloads. The default remains `https://ghfast.top/`; blank restores it. Controller and Agent downloads use the downloading machine’s settings.
- Keep newer releases accessible, bind installation confirmation to the exact operation and terminate superseded Agent tasks without replaying installation.
- Update the AstrBot companion to v0.2.1: allow scoped plain-number menu replies, handle explicit framework wakeups, show configuration guidance for `/dst` in unconfigured sessions and correct read/manage connection diagnostics.
- Default new companion installations to mixed mode, preserve explicit settings, expand room overview/player/mod output and render structured inventories with nested containers and collected condition metrics.

Upgrade both the Controller and standalone Agents for all fixes. Saves, configuration and running game worlds are preserved. Update the companion ZIP separately; existing shortcut-mode installations can select mixed mode to retain natural-language model handling. The broadcast plugin is unchanged.
