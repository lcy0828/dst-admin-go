# v1.3.16

修复页面软件更新被旧任务阻挡的问题，新增可自定义的 GitHub 加速前缀。对应 [Issue #28](https://github.com/lcy0828/dst-admin-go/issues/28)。

- **旧任务自动对账：** 通过镜像或安装包升级后，已被健康运行版本覆盖的待安装、失败或中断任务会明确标记为已失效，新版更新入口保持可用；不会把旧任务误报为安装成功。
- **失效更新包恢复：** 已下载的安装包缺失或校验失败时，可以重新下载，无需清空更新目录。禁止重复安装相同版本，保留有效的未来版本更新包和完整校验。
- **自定义 GitHub 加速：** 软件更新设置新增可见的 HTTPS 加速前缀，默认 `https://ghfast.top/`，留空恢复默认。版本信息、校验文件、安装包与续传共用设置；网络代理仍独立配置。控制端、Agent 自行下载及控制端传包均使用对应下载机器的设置。
- **更新交互与 Agent 回执：** 新版入口不再被旧任务遮住；确认安装绑定具体任务，失效任务清理浏览器中的自动安装意图。Agent 遇到外部升级使任务失效时明确结束等待，不重复下发安装。

控制端与独立 Agent 均需升级才能使用全部修复。普通面板更新保留存档、配置和运行中的游戏世界；本次发布不修改 AstrBot 插件。

## English

- Reconcile obsolete online-update tasks after healthy external image/package upgrades without falsely reporting the old installation as successful.
- Re-download missing or invalid prepared packages, reject same-version reinstallation and retain valid future packages and integrity checks.
- Configure an HTTPS GitHub mirror prefix for release metadata, checksums, archives and resumable downloads. The default remains `https://ghfast.top/`; blank restores it. Controller and Agent downloads use the downloading machine’s settings.
- Keep newer releases accessible, bind installation confirmation to the exact operation and terminate superseded Agent tasks without replaying installation.

Upgrade both the Controller and standalone Agents for all fixes. Saves, configuration and running game worlds are preserved. AstrBot plugin versions are unchanged.
