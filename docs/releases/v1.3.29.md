# v1.3.29

补齐机器人事件播报，配套 AstrBot 插件升级到 v0.4.6。房间维护、季节变化、游戏与模组更新、备份异常及管理程序更新可以直接通知已启用的群，无需模型分析。新增事件记录也可通过 API/MCP 查询和订阅。

- **房间动态：** 记录单房间、批量与定时启停及重启结果，以及异常退出、回档、重置和备份恢复。回档显示实际观测天数，不把存档点数当作天数；缺少载入证据时保留“待确认”。
- **更新提醒：** 区分发现新版、开始更新、安装结果与世界恢复。模组下载完成与重启加载分别记录，已停止的世界不会为通知而启动。管理程序更新与游戏世界重启分别显示。
- **更多游戏事件：** 可分别开启死亡复活、固定原版 Boss 击杀、模组自定义消息及持续性能告警。复用已有活动和性能采集，暂停、缺少采样与无人休眠不会被当作零分告警。模组消息使用受限的纯文本入口。
- **群内设置：** 支持玩家群/管理群通知预设、分类开关和可编辑模板；“最近动态”等常见查询直接读取面板。升级保留原有设置，新增类别默认关闭，不会自动打开采集或扩大权限。
- **断线与补读：** 房间记录保留最近30天、最多10,000条。插件保存读取位置和待发消息，重连补读并过滤过期提醒；任务结果与主动通知共用投递记录。QQ投递结果不确定时不自动重发，也不重新执行游戏操作。
- **API/MCP：** 新增 `api_readRoomNotificationEvents`、`api_streamRoomNotifications` 和 `api_listRoomRecentEvents`，均检查对应房间的读取权限。前端通知事件选择同步更新。

完整设置、支持范围及示例见[机器人事件播报](../robot-event-notifications.md)。

## 升级与兼容

更新包内含配套页面。AstrBot v0.4.6 通过本 Release 的 `astrbot_plugin_dst_companion.zip` 单独安装或升级。旧插件继续使用原入口；新插件连接旧面板时按实际支持的事件降级，原有进退服与聊天能力保留。

模组专用消息入口需要 Runtime 2.4.25；通过现有运行脚本更新入口升级相应机器，远程机器同时更新 Agent。该运行时更新无需重启游戏世界。发布或更新面板程序本身不会主动重启世界。

死亡复活和 Boss 击杀依赖已开启且正常工作的活动采集；Boss 通知只覆盖固定原版名单与可归属玩家的击杀。运行告警沿用性能报表样本。群内打开通知不代表采集已开启或历史完整。QQ平台不提供幂等凭据时，不承诺通知绝对不重不漏。

## 验证

全仓105个 Go 测试包、1003项前端测试及385项插件测试通过；相关 race、vet、OpenAPI 契约检查、前端 lint 和生产构建通过。模组消息通过实际 Lua 产出与 Go 解码的合成边界检查。

本次未在真实 QQ 群或在线游戏房间执行验收；跨节点回档/重置、真实游戏信号覆盖与2C4G实机资源基准仍需在测试环境验证。测试不使用真实令牌、玩家数据或存档。
