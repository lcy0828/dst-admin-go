# v1.3.15

新增官方 AstrBot 伴随助手、稳定机器人能力接口和按用途限制的接入密钥，并缩短发布流程中的重复构建。

- **无需模型的常用操作：** 伴随助手 v0.2.0 支持菜单、房间列表、运行状态、在线玩家、背包、模组、网络档位和备份设置查询，提供房间选择、昵称重名消歧、消息引用和参数补齐。新配置可选择快捷模式，明确使用 `AI:` 才进入模型；旧配置保留原有混合聊天行为。
- **可自定义插件：** 支持全局默认与会话覆盖、菜单顺序、指令别名、结果模板、能力开关、超时和任务通知。兼容的新读取能力可以通过面板目录接入，无需更新插件；新管理能力仍需明确开放。
- **稳定 Bot API / MCP：** 新增能力目录、固定只读查询、管理提交及原请求结果回读四个接口，首批包含 18 项固定能力。`?view=bot` 提供至多 14 个插件依赖入口，并按密钥权限过滤；保留现有 MCP 分页兼容开关。不接收任意 Lua、执行地址或调用者伪造的只读标记。
- **实际权限限制：** 接入密钥可以选择游戏查询、游戏管理、面板管理，并限制允许访问的房间。MCP、REST、工具分发、资源及任务回读共用限制；已有密钥保留原有权限。面板页面同步提供用途与房间配置。
- **可靠的管理回执：** 提交前持久化请求编号，丢回包或插件重载后读取原请求，不自动重复执行。任务下发不等于完成，部分结果、失败与不确定状态分别呈现；自动备份计划保存不等于已经生成备份。
- **播报集成：** 提供可选播报插件 v0.1.2，关联玩家通知与真实消息引用，复用请求额度，保留既有游标及单一投递者。不确定消息投递不会自动重发。
- **发布与同步：** 页面只构建一次，由原生包与镜像复用并校验；复用同提交已通过的 CI，并行构建不同平台。支持从维护机器同步已发布的阿里云镜像，默认仍由 GitHub 同步。普通分支推送执行 CI，版本标签触发正式发布。

**安装与升级：** 面板控制端和页面可在线升级。AstrBot 插件需在机器人端单独安装或升级，Release 提供两个 ZIP 及 SHA256 文件；默认不会自动启用或改写现有机器人配置。完整新协议需搭配 v1.3.15 面板，按[接入指南](https://github.com/lcy0828/dst-admin-go/blob/v1.3.15/docs/astrbot-companion.md)配置连接、会话和房间。已有播报只升级同名实例，保留原配置与状态。

面板升级不会主动重启游戏世界，请先等待已有更新等后台任务结束。原始 `netScore` 和客户端性能档位不换算成毫秒或 FPS；本版本没有新增真实逐玩家 RTT/FPS 采集。

---

Add the official AstrBot companion, stable bot capability APIs and scoped access credentials.

- Common room and player queries, menus, disambiguation and parameter collection run without a model. Configure shortcut mode for explicit `AI:` access; existing configurations retain mixed chat behavior.
- Customize global defaults and session overrides. Compatible read capabilities can arrive through the panel directory without a plugin upgrade; new writes require explicit enablement.
- Four stable API/MCP operations provide a code-owned capability directory, read queries, administrator actions and original-request recovery. The bot MCP view contains up to 14 dependencies and preserves pagination compatibility.
- Enforce credential purpose and room restrictions across REST, MCP, dispatch and result access. Persist request identities before submission and never automatically replay uncertain actions.
- Keep the optional broadcast plugin's cursors and single delivery owner. Publish installable plugin ZIPs with SHA256 files.
- Reuse verified frontend builds and exact-commit CI, parallelize packaging and offer optional local Alibaba Cloud image synchronization.

Update the panel normally; install or upgrade AstrBot plugins separately using the linked guide. Publication does not deploy or reload a running bot. Panel upgrades do not deliberately restart game worlds. Real per-player RTT/FPS collection is not included.
