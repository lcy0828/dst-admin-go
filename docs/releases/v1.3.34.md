# v1.3.34

- 从房间模组页面选择「加入房间」时，优先使用目标机器上已有的模组文件。选中自动处理依赖时，只下载目标机器缺少的模组或依赖。任务标题显示「加入房间」，实际下载仍显示进度。
- 修复世界与模组源码编辑器打开空白。世界设置切换 Lua 和 INI 文件时各自保留草稿。模组编辑器会提示所选世界的配置文件中尚未添加模组。

## English

- Adding a mod to a room reuses ready files on the selected machines and downloads only missing Workshop items, including dependencies when selected. Task progress identifies the room-add operation.
- Fix blank world and mod source editors. World Lua and INI drafts remain separate. The mod editor explains when a world's configuration contains no mods.
