# v1.3.32

修复多行聊天与公告的读取，并改善聊天记录页面的阅读和历史检查入口。

- **多行消息：** 公告或聊天跨日志读取片段时可以接续正文，分批同步和服务重启后保留读取位置；模组警告及调用栈不会再接到上一条聊天后面。正文接续限制为 16 行、4096 字节，避免大段日志占用过多资源。
- **系统与主机消息：** 支持游戏的系统公告，以及没有玩家 ID 的主机聊天和私聊，减少有效消息被忽略的情况。
- **历史记录：** 对旧解析版本分批补读，在原记录上补齐多行内容；地面与洞穴镜像消息继续合并，保留原有记录和来源。同步结果同时返回历史读取状态，便于页面显示实际进度。
- **聊天页面：** 将历史检查信息收进说明弹层，补读中仍保留进度入口；长消息支持展开，改善换行、昵称及游戏图标显示，减少无法显示的字符方框。
- **安装检查：** 已确认退出、尚未回收的游戏进程不会再误报为“无法确认安装路径”；正在运行或状态无法确认的游戏进程仍会阻止安装与更新。

## 升级与兼容

管理程序内含配套页面。已有聊天记录和同步进度会保留，旧记录按有界批次补读；原日志已被删除或轮转出保留范围时，仍只能展示已保存的内容。

API、MCP 工具名、分页兼容设置和 Runtime 脚本版本保持兼容。AstrBot 插件继续使用 v0.4.8，本次无需升级插件。远程节点没有新增 Agent 能力要求。面板程序升级不会主动重启游戏世界。
