# v1.3.31

改进 Steam 登录、AstrBot 玩家查询与操作、聊天同步，以及自动更新设置。随包提供 AstrBot 饥荒助手 v0.4.8。

- **Steam 登录（#36）：** 支持仅填写用户名，复用运行节点已保存的 SteamCMD 凭据；也可在密码登录时填写一次性 Steam Guard 验证码，或在手机确认无响应时改用验证码。缺少缓存、密码错误、验证码过期和登录限流会分别提示。
- **玩家查询：** 改进离线玩家活动、轨迹与背包查询，保留背包来源选择；默认来源按存档时间选择，仍可手动切换。引用已验证的玩家消息、昵称补齐与分组菜单使用统一的目标解析。
- **群内操作：** 取消或切换请求后，排队中尚未提交的修改不会继续发送；已经提交的操作保留原回执查询，不自动重复执行。物品发放支持单次最多 400 个、最多 40 组，仍受物品与权限校验限制。
- **常见地点：** 增加当前世界的出生点、猪王、月岛等地点查询及传送预检；已保存的同名地点优先，选择结果保留地点标识，防止名称变化后指向其他位置。
- **聊天记录：** 修正地面与洞穴镜像记录导致的重复消息，保留同一世界中玩家实际重复发送的内容；页面在打开时自动刷新聊天。
- **更新设置：** 集中显示游戏与模组无人自动更新的设置、开关和等待状态，改善新建房间的设置入口；保留已有房间的选择。
- **页面与安全：** 改善弹窗、深色主题和多语言显示；构建工具链升级至 Go 1.26.11，修复标准库漏洞 GO-2026-6859。

## 升级与兼容

管理程序内含配套页面。AstrBot 使用本 Release 的 `astrbot_plugin_dst_companion.zip`（v0.4.8），保留原配置与状态。原 API、MCP 工具名及分页兼容设置继续保留；兼容现有协议的新增接口仍可通过能力发现使用，不自动扩大群权限。

远程节点使用新的 Steam 登录方式时，需要同时升级 Agent，支持 `runtime.steam-login.v2`；旧账号密码登录保留原接口。用户名模式要求相同运行环境、系统用户和 SteamCMD 能访问已保存的凭据；宿主机登录不会自动把凭据复制到容器或其他机器。缓存失效仍需重新登录，一次性验证码只用于当次验证，不会持久保存。

本次不增加 Runtime 脚本版本要求，沿用 2.4.26。面板与插件升级不会主动重启游戏世界。

## English

- Add username-only cached SteamCMD login and one-time Steam Guard code fallback for #36; require upgraded Agents for the new login payloads.
- Improve offline player queries, inventory source selection, verified message references and grouped menus in AstrBot v0.4.8.
- Prevent queued, unsent writes from running after request cancellation or replacement; recover submitted operations by their original receipt.
- Add bounded item grants and current-shard landmarks while preserving saved-location identity and existing API/MCP compatibility.
- Deduplicate mirrored shard chat, refresh visible chat automatically, and improve unattended update settings and UI consistency.
- Build with Go 1.26.11 to address GO-2026-6859. Existing configuration is preserved; upgrading does not restart game worlds.
