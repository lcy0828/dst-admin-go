# v1.3.21

完善外部 AI 与 AstrBot 接入，减少日常查询的等待和参数错误，同时改进聊天推送、模组展示与公告结果。

- **自然提问自动处理：** AstrBot 中直接 `@机器人` 或输入 `/dst 需求` 即可。常用查询直接读取面板，其他问题自动交给模型；菜单选择、补充昵称、取消和多轮追问继续衔接，无需添加 `AI:`。
- **更少、更清晰的 AI 工具：** 新建 MCP 连接推荐任务视图，按权限提供最多 9 个入口，涵盖房间、玩家、世界、能力发现和任务结果。支持昵称解析与重名选择，保留完整 OpenAPI、旧 MCP 视图和分页兼容选项。
- **群权限与操作确认：** 插件支持内部使用一条面板连接，按 QQ 成员、管理员、群主分配权限。模型提出的修改需用户确认；明确的快捷管理指令沿用原有授权。结果不确定时回读原任务，避免重复提交。
- **查询结果更可靠：** 活动、轨迹、战斗和性能查询保留结构化数据、分页与缺口说明；时间附带北京时间解释，跨世界记录补充世界名称。非法参数在提交前拒绝，缺失数据不显示为零。
- **游戏聊天持续推送：** 新增房间聊天 SSE 接口，支持游标续读、跨世界副本合并和有限保留。AstrBot 对支持的面板优先使用推送，旧面板继续使用轮询。
- **暂停与重置提示：** 正常暂停时，玩家列表显示采样暂缓并保留原采样时间，实际读取异常仍会提示。总览新增“重置全部世界”入口，明确会清除整个房间的进度；全部世界运行后才可提交，操作前建议手动备份。
- **模组与公告展示：** 机器模组列表和下载进度复用图标；未启用的模组也可预览配置。公告区分已提交、已确认和结果未确认，共用广播的世界不再误报为失败。
- **插件更新与兼容：** 新增可选的插件更新检查、签名验证、取消下载与加载失败回退。默认手动更新；自动安装需要发布者提供受信签名包。兼容的新面板能力可通过目录发现，已有群授权不会因升级自动扩大。

普通面板升级保留配置、存档和运行中的世界。AstrBot 插件包单独提供；已有部署保留原权限模式，切换群角色模式请由维护者配置。

本次附带 **AstrBot v0.4.0** 安装包。当前发布尚未配置插件更新签名，请通过安装包手动更新；安装后不会自动启用自动更新。

验证：后端相关回归与并发检测、前端 960 项测试、AstrBot 322 项测试通过。真实 QQ 客户端的完整交互验收尚未完成，插件实群体验仍需验证。

本次功能与修复由 [@lcy0828](https://github.com/lcy0828) 维护。

## English

- Route ordinary AstrBot mentions and `/dst` requests automatically between direct queries and AI, with improved menu, nickname, cancellation and follow-up handling.
- Add a task-oriented MCP view with up to nine permission-scoped tools while preserving existing API and MCP contracts.
- Support a private panel connection and QQ group-role permissions; require user confirmation for model-proposed writes and read back uncertain tasks without replaying them.
- Preserve query evidence, timestamps, pagination and cross-world context; add resumable room chat streaming with polling compatibility.
- Distinguish paused player sampling from read failures, preserve sample timestamps, and expose whole-room world reset with explicit scope and confirmation.
- Improve mod thumbnails and configuration previews, clarify announcement delivery outcomes, and add optional signed plugin updates with download cancellation and rollback.

Ordinary panel updates preserve configuration, saves and running worlds. Plugin upgrades retain existing authorization settings.

The release includes AstrBot v0.4.0 for manual installation. Signed plugin updates are not configured for this release. Automated backend, frontend and plugin checks passed; complete native QQ client acceptance remains pending.
