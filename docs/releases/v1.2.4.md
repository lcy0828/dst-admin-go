控制端与 Agent 现支持页面在线更新，普通更新无需重新拉取镜像。

- 顶部显示当前管理服务版本并提示新版；在 **系统设置 → 软件更新** 下载、校验和更新控制端及内置前端。
- 在 **机器详情 → 诊断** 单独更新 Agent。默认由 Agent 自行下载，也可选择控制端传包；支持 Linux amd64/arm64、macOS amd64/arm64 和 Windows amd64 的 Agent 包。
- 页面显示下载进度和速度，短暂断网后继续跟踪同一任务；修复更新回执丢失导致的误报，避免重复安装。
- 更新只允许向前升级。新程序启动或重新连接失败时自动恢复原程序，恢复结果在重启后保留。
- 保留配置、身份、存档和运行中的游戏进程；下载更新包期间暂停管理方式与目录的热应用，避免中断下载。
- 升级 Go 工具链与网络依赖，修复漏洞扫描报告中的标准库和 HTTP/2 问题。

**首次升级：** `v1.2.1` 及更早版本尚未包含在线更新功能。Docker 用户在原部署目录执行 `docker compose pull && docker compose up -d`，保留原有数据挂载；原生部署使用对应平台的完整安装包。之后可在页面更新普通版本，系统依赖变更仍需更新基础镜像或完整安装包。

国内用户推荐使用阿里云镜像源；其他用户可使用 Docker Hub。完整部署和支持范围见 [README](https://github.com/lcy0828/dst-admin-go#readme)。Windows Agent 支持连接与程序更新，暂不支持运行原生 Windows DST。

Controller and Agent updates are now available in the web UI.

- View the running version in the header and update the Controller with its embedded UI under **System settings → Software updates**.
- Update each Agent under **Machine details → Diagnostics**. Agents download directly by default, with an optional Controller relay. Agent downloads cover Linux amd64/arm64, macOS amd64/arm64 and Windows amd64.
- Follow download progress and speed, resume observation after temporary connection failures, and avoid duplicate installation when acknowledgements are lost.
- Only forward upgrades are offered. Failed startup or reconnection automatically restores the working program, including after a subsequent restart.
- Configuration, identity, saves and running game processes are preserved. Configuration hot application waits for active software downloads to finish.
- Update the Go toolchain and network dependency to fix reported standard-library and HTTP/2 vulnerabilities.

**First upgrade:** versions up to `v1.2.1` require one full image or native-package update to enable this feature. Keep existing data mounts. Routine updates can then use the web UI; system dependency changes still require a new base image or full package. Native Windows DST remains unsupported.
