# v1.3.26

游戏工作台补充拾取、种植、维修和角色设置。操作前先查看影响范围，确认后执行，并区分效果已确认、跳过、失败和待确认。配套 AstrBot 插件升级到 v0.4.4。

- **拾取与维修：** 拾取玩家附近的地面物品，支持堆叠合并和部分接收；背包已满时保留原物。维修只处理地面装备的使用次数和护甲耐久，不补燃料、不修改容器内物品。
- **种植操作：** 支持为适配的原版植物施肥、推进一个生长阶段、催熟及采摘。施肥由管理员补充，不扣玩家材料；未知植物和模组私有产出不会使用通用计时器兜底。采摘产物合并后无法核实去向时仍显示待确认。
- **重建烧毁科技站：** 支持原版科学机器和炼金引擎，保留位置、朝向和可用皮肤；不能找回烧毁前丢失的数据，不替换箱子、锅、船等其他建筑。
- **角色设置：** 增加附加饥饿消耗倍率、伍迪恢复人形和旺达年龄段调整。解除倍率只移除面板自己的效果，保留其他模组设置；不跨登录或换世界自动重新施加。角色变化短时等待原生动画和状态确认，不补满属性或恢复冷却。
- **统一确认与结果：** 面板、MCP 和插件读取同一份动作说明与交互要求。预览固定玩家、对象和范围，只能确认执行一次；模型不能代替原用户确认。超时、输出缺失或修改后异常不会当作成功，也不会自动重发。
- **机器人与界面修复：** 新版插件可直接处理明确的施肥、催熟、拾取、饥饿倍率和恢复人形指令，复杂问题仍直接交给 AI。修复世界信息检索遗漏、模型漏填用户明确指定的世界，以及“我的背包”追问后昵称无法接续的问题。结果和历史记录明确区分预览与执行，物品名称优先显示中文。

## 升级与兼容

新操作需要 Runtime 2.4.23，完整群内交互需要 AstrBot 插件 v0.4.4。更新面板后，请通过现有游戏管理脚本更新入口提供新能力；远程机器还需同步升级 Agent。旧 Runtime 缺少能力时在修改前提示升级，原有第一版回执和查询保持兼容。

发布新版及更新面板程序不会主动重启游戏世界。普通启动房间不会自动重写游戏管理脚本、模组或世界配置。插件代码需单独更新，不能只更新面板就假定旧插件支持新的确认流程。

附近操作有范围、对象、产出、执行次数和输出大小限制，数量过多时需缩小范围。同步游戏组件方法不能被强制中断；结果待确认时请查看原任务，不要重复提交。完整范围见[工作台使用说明](../workbench-actions.md)。

## 验证与范围

已完成两轮自审、后端回归与并发检测、351 项插件框架测试、983 项前端测试、检查构建和桌面／移动端页面检查。在独立原生游戏世界中验证了拾取、堆叠、满包、维修、种植、饥饿倍率、旺达年龄、伍迪人形恢复和科技站重建，并回放校验原生结果。

日食暂未开放。真实双世界、远程 Agent／跨节点、新动作的真实 QQ 完整流程和 2C4G 性能基准仍未全部验收；不将单世界结果当作这些环境的验证。跨世界迁移、连续地皮、阵列、道路和模式持久记忆继续跟进，[#30](https://github.com/lcy0828/dst-admin-go/issues/30) 保持开启。
