# v1.3.23

修复外部 AI 查询玩家时被误拒绝的问题，改进工作台操作查找、玩家模式管理和附近操作确认。

- **玩家查询默认可用：** 游戏查询、游戏管理密钥调用 `api_listRoomPlayers` 时，可以省略 `includeAccessLists`。API、原生 MCP 和 `call_api` 使用一致的规则，明确请求管理名单仍需要面板管理权限。管理员和旧插件保留原有行为。
- **AI 更容易找到操作：** 工作台、MCP 与 AstrBot 共用具体动作名称、搜索词和参数建议，覆盖天气、角色能力、玩家能力及附近操作。任务工具仍保持最多 9 个入口，不自动扩大群权限。
- **玩家模式可查可管：** 增加固定只读查询 `player_modes`，区分已开启、已关闭和无法确认。普通免伤与综合无敌分别展示；关闭模式时保留原本已有的效果，遇到来源冲突会提示核对。
- **附近操作先看范围：** 灭火、冻结、催眠、平息仇恨、删除和击杀先预览，再确认。预览限定目标、有效期和执行次数；结果分别显示已确认、未确认、跳过和失败，避免把“已发送”当作完成。
- **AstrBot v0.4.2：** 支持具体工作台动作发现和明确短指令处理，完善范围操作的人工确认、取消、过期与结果展示。复杂表达继续交给 AI，既有授权规则保持有效。

玩家查询修复不要求升级插件。新版工作台模式归属和范围预览需要 Runtime 2.4.21；旧 Runtime 不支持时会明确提示，不能把仅发送命令当作成功。面板升级保留存档和运行中的世界，不会自动开启玩家模式；插件安装包单独提供，需手动更新。

本版完成自动化回归与并发检测，实际游戏模组组合和 QQ 群交互仍应以使用环境为准。传送点、安全传送及部分低频编辑功能不在本版范围，Issue #30 继续跟进。详见[工作台使用说明](../workbench-actions.md)与[AI 接入说明](../ai-assistant.md)。

修复 [#31](https://github.com/lcy0828/dst-admin-go/issues/31)，继续完善 [#30](https://github.com/lcy0828/dst-admin-go/issues/30)。

## English

- Fix default player queries for game-read and game-manage credentials across REST, native MCP and `call_api`. Explicit management-list reads remain permission-gated; existing administrator and plugin behavior is preserved.
- Improve fixed workbench action discovery across the panel, MCP and AstrBot without adding top-level task tools or expanding group permissions.
- Add read-only player-mode observations and separate ordinary invincibility from comprehensive god mode. Preserve pre-existing effects when disabling panel-owned modes; report uncertain ownership explicitly.
- Require preview and confirmation for six nearby actions, with bounded targets, expiration, one-time consumption and structured outcome reporting.
- Include AstrBot v0.4.2 for action discovery, direct commands and human confirmation flows. Player-query fixes also work with older plugins.

New workbench protections require Runtime 2.4.21. Panel updates preserve saves and running worlds; plugin installation remains manual. Automated checks use isolated fixtures; compatibility with actual game mods and QQ conversations depends on the deployment. Additional enhancements remain tracked in #30.
