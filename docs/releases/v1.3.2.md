修复控制台命令、访问名单、实体目录和游戏表情显示，改善受限网络下的创意工坊访问。

- **创意工坊网络设置：** 支持自定义 Steam API / 社区基地址，以及使用系统代理、直连或自定义代理；页面可测试连接并保存后立即生效。配置 Steam Web API Key 时优先使用官方 JSON 接口，无 Key 时保留社区搜索。访问仍取决于所选入口及代理是否可达。
- **模组浏览：** 合并重复请求，限制并发、超时和缓存大小；网络异常时展示具体原因及可用的缓存结果。缩略图由控制端缓存，减少浏览器直连 Steam 图片服务造成的加载失败。
- **控制台命令（#4）：** 修复 `<`、`>`、`<=`、`>=` 被转义成字面量而导致 Lua 编译或执行失败的问题，覆盖本机和 Agent、短命令和文件传输。
- **访问名单（#5）：** 兼容 UTF-8 BOM 和带 BOM 的 UTF-16 文件；读取不会改写原文件。格式错误显示文件与行号，读取失败提供阶段和请求编号，便于继续定位现场原因。
- **实体目录（#6）：** 为目录和世界快照增加分页、关键字搜索及快照一致性检查，同步 OpenAPI / MCP 工具参数，避免大目录默认触发 `AI_RESULT_TOO_LARGE`。工作台继续支持完整目录的本地筛选和排序。
- **游戏表情（#8）：** 内置约 93 KiB 的游戏表情字体，支持房间名、玩家名、聊天及输入框中的 50 个游戏私有区表情；字体图案来源为 Klei Entertainment，仅在用到这些字符时加载。
- **页面布局（#3）：** 修复侧边栏展开时顶部面包屑被挤成竖排并溢出的问题，统一工作台分类计数与当前列表的统计口径。

**贡献致谢：** 感谢 [@hxyinan](https://github.com/hxyinan) 提交 [PR #9](https://github.com/lcy0828/dst-admin-go/pull/9)，加入可配置的 Steam API / 社区基地址、系统设置字段和配置样例，为受限网络下的模组访问提供可用入口。本版本在此基础上加入即时生效、连接测试及请求与缓存管理。

**升级：** 可在 **系统设置 → 软件更新** 更新控制端；独立 Agent 可在 **机器管理** 中更新。Docker 用户也可拉取 `v1.3.2` 或 `latest` 后重建容器。前端已包含在管理程序与镜像中，无需单独部署；升级无需删除存档。

Fixes console commands, access lists, entity catalogs and game emoji rendering, and improves Workshop access on restricted networks.

- Configure Steam API / Community base URLs and system, direct or custom proxy access. Test connections and apply settings immediately. Searches prefer the official JSON API when a Steam Web API key is configured; Community search remains available without a key. The selected endpoints or proxy must be reachable.
- Coalesce duplicate Workshop requests and bound concurrency, timeouts and caches. Show actionable network errors and cached results when available; cache mod thumbnails through the Controller.
- Fix Lua comparison operators being changed into literal escape text during local and Agent console command delivery, for both direct commands and request documents (#4).
- Read UTF-8 BOM and BOM-marked UTF-16 access lists without rewriting their original bytes. Report the file and line for invalid entries, and the failure stage and request ID for read errors (#5).
- Add pagination, keyword filtering and snapshot consistency checks to entity directory APIs and OpenAPI / MCP tools. Default pages fit the AI result budget, while the workbench retains complete local filtering and ranking (#6).
- Bundle a roughly 93 KiB font for 50 DST private-use emoji in room names, player names, chat and inputs. Artwork is from Klei Entertainment; the font loads only when those characters are used (#8).
- Prevent header breadcrumbs from collapsing into vertical text with the sidebar expanded, and make workbench category and list counts consistent (#3).

**Contributor:** Thanks to [@hxyinan](https://github.com/hxyinan) for [PR #9](https://github.com/lcy0828/dst-admin-go/pull/9), which introduced configurable Steam API / Community base URLs, settings fields and configuration examples. This release builds on that contribution with live application, connection tests, and bounded requests and caches.

**Upgrade:** update the Controller under **System settings → Software updates**, and standalone Agents under **Machines**. Docker users can pull `v1.3.2` or `latest` and recreate their containers. The frontend is embedded in the management program and images; game saves do not need to be deleted.
