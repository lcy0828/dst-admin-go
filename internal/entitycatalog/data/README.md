# Vanilla display metadata

`vanilla.json` contains Prefab IDs, Chinese/English display names and resource
categories from [Klei Entertainment's Don't Starve Together](https://www.klei.com/games/dont-starve-together),
game build 747465. Categories use the official scrapbook's type/subcategory and
existing curated common entries. Unknown/internal Prefabs remain `other`.

The directory is display metadata, not a claim that a particular world has
registered an entity or supports inventory operations. It contains no game
scripts or textures. Artwork is distributed separately as an optional resource
pack; game content remains the property of its respective owners.
